# welcome voice player
## what is the device is for
this project is to fill the market gap of welcome greeting devices appeared in sri lanka in recent times.
this device can be used as a separate module for all vehicles having 4 and up wheel count. once the key is entered, and power is supplied to the device it will play the costome made audio nicely.
the audio track is used is different to vehical to vehical.and can be customed according to the user's(vehical owner/driver) preference
## workings
Device is consists of the following componentes,
1. waveshare rp-2040 Zero MCU module
2. MAX98357 I2S amplifier module
3. MP1584/LM2596 Buck-Converter module
4. 5W 4ohm speaker
5. 3D-printed audio enclosure

the welcome audio track is stored in the flash memory in .wav format,mono format along with the micropython controller progrtamm.
once the power power is supplied to the buck-converter the audion track will be played after a 5 second delay.
